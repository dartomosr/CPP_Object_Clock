# C++ Object Clock

Веб-обои для Wallpaper Engine показывают локальное время и дату в виде листинга кода. По умолчанию `main.cpp` открывается в режиме Modern C++ с темой Code Blocks и размером шрифта 64 px. При запуске код набирается построчно. Включены рамка IDE, номера строк, мигающий курсор и строка состояния.

## Запуск

Откройте существующий проект через `project.json` в редакторе Wallpaper Engine и запустите предпросмотр. Для просмотра стандартных настроек в браузере откройте `index.html`. Все шрифты, темы и скрипты поставляются локально. Node.js нужен только для разработки.

## Синтаксис и значения

| Режим | Представление |
| --- | --- |
| C | Переменные в `main.c`, массивы `char[]` для строк |
| C++ | Явные типы `int` и `string` в `main.cpp` |
| Modern C++ | Объявления с `auto` |
| Struct / Class | Класс `TimeSnapshot` с конструктором и закрытыми полями |
| Pointers & Memory | Указатели, виртуальные адреса и значения при разыменовании |
| Template / constexpr | Шаблон `ClockTraits` с константами и методом `consteval` |
| x86 Assembly | Загрузка снимка в регистры и байты инструкций. Строки представлены виртуальными адресами с текстовой аннотацией |
| GLSL Shader | Числовые поля в виде uniform-переменных. Час, минута и секунда задают каналы цвета фрагмента. Текстовые значения показаны в комментариях |
| C# Modern / Top-Level | `Program.cs` создаёт `record struct TimeSnapshot` и выводит снимок через интерполяцию |
| C# Class / Properties | `SystemClock.cs` содержит свойства с `get; init;` и атрибут с часовым поясом |
| C# LINQ / Async | После `await Task.Delay(1000)` цепочка `Where`, `Select` и `ToArray` форматирует поля |

**Number base** задаёт представление чисел в листинге. Например, 14 секунд отображаются как `14`, `0b1110`, `0xE` или `"XIV"`. В римской записи ноль обозначен `N`, а скобки умножают группу на тысячу. Это позволяет вывести и Unix-время. Названия месяцев и остальные текстовые поля сохраняют исходный вид.

12-часовой формат применяется до смены системы счисления. Ведущие нули действуют на часы, минуты, секунды и день. В десятичном режиме получаются строки вроде `"08"`, в двоичном и шестнадцатеричном числа дополняются до восьми бит и двух hex-цифр соответственно. SUS Mode заменяет все значения в листинге строкой `"SUS"`.

Переключатели видимости и расположения позволяют выбрать поля и привязку блока к экрану. При их отключении восстанавливаются стандартные поля и центрирование. Часовой пояс поддерживает смещения с минутами, например `GMT+05:45`.

## Окружение редактора

- **IDE frame** включает шапку, вкладку с именем файла, нумерацию и направляющие отступов. Для классического минималистичного вида отключите рамку, курсор и строку состояния.
- **Status bar** показывает диалект и позицию курсора. При переходе на новую минуту появляются `Compiling…` и `Build succeeded`. **Console output** выводит локальное время и статус тика.
- **Dynamic comments** учитывают время суток и календарные даты. **Progress comment** показывает долю текущей минуты или дня.
- **Debugger watch** показывает тип, размер и виртуальный адрес при наведении на имя переменной или регистр. Размеры моделируют x86-32 для ассемблера и 64-битную конфигурацию для C/C++. Адреса синтетические и постоянны для каждого поля.
- **Highlight changed values** подсвечивает значения при изменении. **Typewriter effect** набирает листинг при запуске, включении эффекта и переключении синтаксиса. Курсор имеет собственный переключатель.

### Управление с рабочего стола

Все опции этого раздела по умолчанию выключены.

- **Interactive IDE controls** делает вкладки в шапке кликабельными. Три кнопки слева по порядку сворачивают окно до строки со временем, скрывают рамку и повторяют анимацию печати. Вернуть окно можно кнопкой **Restore**.
- **Draggable window** позволяет перетащить окно за свободную часть шапки или за ручку справа. Позиция сохраняется в локальном хранилище относительно доступного места на экране. Кнопка **Center** возвращает окно в центр. **3D parallax tilt** включает мягкий наклон вслед за указателем.
- **Theme switcher** открывает меню **Palette**. Выбранные на рабочем столе тема и вкладка действуют в текущем сеансе. Выбор палитры включает ручной режим на этот сеанс. Постоянный выбор задаётся в свойствах Wallpaper Engine.
- **Compiler warnings** подчёркивает час во время ночной сборки, секунду на границе минуты и значение секунды в SUS Mode. Наведите указатель на подчёркнутое имя для пояснения.
- **Keyboard easter eggs** включает команды `segfault`, `vim` и `matrix`. Первые две временно открывают вывод терминала, третья на шесть секунд запускает ускоренный дождь Matrix. Кнопка **>_** позволяет вызвать те же эффекты мышью. Набор с клавиатуры работает, когда хост передаёт странице события клавиш. Для обоев из Workshop используйте мышь. [Пояснение разработчика Wallpaper Engine](https://steamcommunity.com/app/431960/discussions/1/3035978213221471274/)
- **Audio spectrum** показывает восемь частотных полос под кодом, от басов слева до высоких частот справа. Используются оба канала системного звука. На паузе обработка спектра останавливается. [Документация Wallpaper Engine](https://docs.wallpaperengine.io/en/web/audio/visualizer.html)

## Темы и фон

В проекте 21 тема, включая Rosé Pine и Dawn, Gruvbox, Dracula Official, Catppuccin Mocha, Tokyo Night, Nord и Monokai Pro. Blueprint добавляет чертёжную сетку. Retro CRT Terminal использует зелёный люминофор, сканлайны и виньетку. Автосмена использует выбранную дневную тему с 07:00 и ночную с 19:00 по локальному времени. Для ручного выбора отключите автосмену.

Выберите свой файл в **Add background** в группе **Environment**. Изображение заполняет экран и видно за кодом даже с включённой рамкой IDE. **Semi-transparent text panel** добавляет подложку для читаемости. Очистка выбранного файла возвращает фон темы.

Настройка **Procedural background** предлагает чертёжную сетку, созвездие с параллаксом, секундный импульс осциллографа и дождь из символов C++, битов или hex-байтов. Canvas рисуется поверх выбранного изображения. **None** отключает Canvas. Цвет линий и символов задаёт активная тема.

В этом же меню доступны звёздное поле с параллаксом, печатная плата с импульсами, Matrix, вращающиеся каркасные многогранники и поле линий на шуме Перлина. Каждый сезон можно выбрать вручную. **Auto Season** берёт локальный месяц и использует сезоны Северного полушария. С декабря падает снег, с марта кружатся лепестки, с июня мерцают светлячки, с сентября летят листья.

Ползунок **Wallpaper scale (code font size)** задаёт размер шрифта кода в пикселях. Вместе с ним масштабируются шапка IDE, строка состояния, консоль, всплывающий инспектор и детали оформления, включая фоновые сетки, волны и символы. Фоновая фотография заполняет экран. Если листинг превышает доступную область, редактор и инспектор дополнительно уменьшаются в одной пропорции. Семейство шрифта можно выбрать после включения настройки оформления.

## Разработка

| Файл | Ответственность |
| --- | --- |
| `project.json` | Настройки Wallpaper Engine и метаданные |
| `scripts/clock.js` | Снимок времени, форматирование и строки всех режимов без DOM |
| `scripts/settings.js` | Дефолты, валидация частичных обновлений, выбор темы и видимых полей |
| `scripts/view.js` | DOM, интерактивный редактор, перетаскивание, инспектор и меню |
| `scripts/backdrop.js` | Процедурные сцены Canvas, палитра и ограничение частоты кадров |
| `scripts/main.js` | События Wallpaper Engine, системный аудиоспектр, таймер, цикл кадров и пауза |
| `styles/*.css` | Общая геометрия, анимации, шрифты и палитры |

Часы перечитывают системное время при смене секунды. Строки сохраняют узлы DOM между тиками. Canvas рисуется с частотой до 24 кадров/с и учитывает более низкий лимит FPS в настройках Wallpaper Engine. На паузе останавливаются таймер, цикл кадров и CSS-анимации. Снятие с паузы сразу применяет накопленные настройки и показывает текущее время.

После изменения исходников выполните обе команды в каталоге проекта с Node.js 18 или новее. Установка пакетов не требуется.

```powershell
npm run build
npm run check
```

Сборка создаёт классический скрипт `scripts/runtime.js`, который загружает Wallpaper Engine. Проверка сверяет его с исходниками, проверяет синтаксис и запускает тесты из `tests/clock.test.js`. Для отдельного запуска тестов используйте `npm test`. При добавлении темы обновите CSS-файл, `THEMES` и списки ручной, дневной и ночной тем в `project.json`.

Проект основан на [js-object-clock](https://github.com/unktir/js-object-clock) автора unktir.
